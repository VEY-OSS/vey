# LTS release notes

Release notes for Long-Term Support cuts live in this directory.

Naming:

- English: `<app>-v<major>.<minor>.<patch>.md`
- Simplified Chinese: `<app>-v<major>.<minor>.<patch>.zh_CN.md`

Examples:

- [`vey-proxy-v1.14.0.md`](vey-proxy-v1.14.0.md)
- [`vey-proxy-v1.14.0.zh_CN.md`](vey-proxy-v1.14.0.zh_CN.md)

See [Long-Term Support](../long-term_support.md) for supported LTS branches.
