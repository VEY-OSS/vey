*****
dummy
*****

This server has a name and does not open a listen socket. It does not receive
requests.

.. versionadded:: 0.10.0

The following common keys are supported:

* :ref:`name <conf_server_common_name>`
* :ref:`type <conf_server_common_type>`

This server type has no server-specific configuration keys.
