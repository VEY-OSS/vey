############
Proxy-Status
############

Locally generated HTTP error responses include a ``Proxy-Status`` header as
defined in `RFC 9209 <https://www.rfc-editor.org/rfc/rfc9209.html>`_.

The header can be disabled with :ref:`no_proxy_status <config_server_http_proxy_no_proxy_status>`
on ``http_proxy`` / ``http_rproxy``, or :ref:`no_proxy_status <conf_auditor_no_proxy_status>`
on the auditor for intercept-generated errors.

This header is **not** added to:

* successful CONNECT replies (``200``)
* successful protocol upgrades (``101``), including MASQUE CONNECT-UDP
* responses forwarded from upstream

CONNECT and Upgrade **failures** still include the header, because those replies
are ordinary HTTP error responses generated by the proxy.

Identifier
==========

The list member identifies this hop:

* the front-end :ref:`server_id <config_server_http_proxy_server_id>` when the
  error is generated by ``http_proxy`` / ``http_rproxy``
* the auditor :ref:`server_id <conf_auditor_server_id>` when the error is
  generated during HTTP interception
* ``vey-proxy`` otherwise

The identifier is encoded as an RFC 9651 token when possible, and as a quoted
string otherwise. This phase does not send ``next-hop`` or ``details``.

Error types
===========

The ``error`` parameter is the most specific RFC 9209 proxy error type for the
local failure. Status codes (including the non-standard 52x codes) are
unchanged.

+----------------------------------+----------------------------------+
| Typical local condition          | ``error`` token                  |
+==================================+==================================+
| Connect timeout                  | ``connection_timeout``           |
+----------------------------------+----------------------------------+
| Connection refused               | ``connection_refused``           |
+----------------------------------+----------------------------------+
| Connection reset                 | ``connection_terminated``        |
+----------------------------------+----------------------------------+
| Network / host unreachable       | ``destination_ip_unroutable``    |
+----------------------------------+----------------------------------+
| Destination address forbidden    | ``destination_ip_prohibited``    |
+----------------------------------+----------------------------------+
| DNS timeout                      | ``dns_timeout``                  |
+----------------------------------+----------------------------------+
| Other DNS failure                | ``dns_error``                    |
+----------------------------------+----------------------------------+
| Upstream TLS handshake failure   | ``tls_protocol_error``           |
+----------------------------------+----------------------------------+
| ACL / auth / user blocked        | ``http_request_denied``          |
+----------------------------------+----------------------------------+
| Malformed or unsupported request | ``http_request_error``           |
+----------------------------------+----------------------------------+
| Upstream protocol / negotiation  | ``http_protocol_error``          |
+----------------------------------+----------------------------------+
| Upstream read/write closed early | ``connection_terminated``        |
+----------------------------------+----------------------------------+
| Upstream response timeout        | ``http_response_timeout``        |
+----------------------------------+----------------------------------+
| Escaper / origin unavailable     | ``destination_unavailable``      |
+----------------------------------+----------------------------------+
| Internal proxy failure           | ``proxy_internal_error``         |
+----------------------------------+----------------------------------+
| Forwarded-loop detection         | ``proxy_loop_detected``          |
+----------------------------------+----------------------------------+

Example:

::

    HTTP/1.1 530 Origin DNS Error
    Proxy-Status: vey-proxy; error=dns_error
    Content-Type: text/html
    Content-Length: ...
    Connection: keep-alive
